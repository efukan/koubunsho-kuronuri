# 公文書くろぬり 利用の手引き

公文書くろぬりは、PDF の一部を黒塗り（墨消し）した「開示用PDF」を作るためのアプリです。インターネットに接続しない端末（LGWAN 端末など）で、管理者権限なしで動きます。

## 1. 動作環境と導入

- Windows 10 / 11（64 ビット）。.NET Framework 4.8（Windows に標準で入っています）。
- 配布 ZIP を任意のフォルダに展開し、`Kuronuri.exe` を起動します。インストールは不要です。
- 同じフォルダに `pdfium.dll` が必要です。ZIP 内のファイルは全て同じフォルダに置いてください。
- 本アプリは外部と通信しません。更新確認・利用状況の送信もしません。

## 2. 作業の流れ

1. **開く**（Ctrl+O）: 黒塗りしたい PDF（原本）を開きます。原本は読み取り専用で開き、書き換えることはありません。
2. **黒塗りする**: 右側の「黒塗りプレビュー」で、矩形や手書きで黒塗り箇所を描きます。左側には原本がそのまま表示されます。
3. **理由を付ける**: 箇所リストで箇所を選び、理由（号番号）を設定します。理由が未設定の箇所は橙色で表示されます。
4. **確認用PDFに保存**（「保存」→ Ctrl+S）: 上司・担当課の確認用に「確認用PDF」を保存します。後でこのファイルを開けば、続きから作業できます。
5. **開示用PDFを作成**（Ctrl+E）: 外部に交付する「開示用PDF」を作ります。作成後、黒塗りの下の文字や情報が残っていないことを自動で検証します。

保存や作成が終わったことや注意は、ページの上に通知として表示されます（緑=完了、青=お知らせ、黄=注意）。困ったときは **F1** キー（または右上の「?」）でこの手引きを画面に表示できます。

### 言葉の意味

| 言葉 | 意味 |
|---|---|
| 原本 | 開いた元のPDF。このアプリは原本を書き換えません |
| 黒塗り箇所（箇所） | 理由を1つ持つ黒塗りのまとまり。矩形や手書きの線をいくつか含められます |
| 理由 | 号番号と名称（例「1号 個人情報」）。自由記述も付けられます |
| 確認用PDF | 原本と黒塗り箇所を中に入れた、庁内確認と作業の保存のためのPDF（`〇〇_庁内確認用.pdf`）。外部に渡してはいけません |
| 開示用PDF | 黒塗りを画像に焼き込んだ、外部に交付するためのPDF（`〇〇_開示用.pdf`） |

## 3. 画面とツール

| ツール | キー | 操作 |
|---|---|---|
| 選択 | V | クリックで選択、ドラッグで移動。矩形1つだけの箇所は四隅・辺のハンドルで大きさを変えられます。Shift / Ctrl を押しながらクリックで複数選択。何もない所からドラッグすると、囲んだ箇所をまとめて選択。矢印キーで 1pt（Shift+矢印で 10pt）ずつ動かせます |
| 矩形 | R | ドラッグで黒塗りの矩形を作ります（ごく小さいものは無視されます） |
| 文字 | T | 文字の上をドラッグすると、その間の文字を行ごとに覆う黒塗りを作ります（文字情報のない所では矩形と同じ） |
| 手書き | B | ドラッグで線を描きます。近くに続けて描いた線は1つの箇所にまとまります。Enter / Esc で区切れます |
| 消しゴム | E | クリックした図形を消します |

- 太さは「太さ」欄または `[` / `]` キーで変えます。
- 「現在の理由」を選んでおくと、新しく描く箇所にその理由が付きます。
- **Space キーを押している間**、黒塗りが透けて下の文字を確認できます。
- 「結合」（Ctrl+G）で同じページの複数の箇所を1つに、「分割」（Ctrl+Shift+G）で1つの箇所を図形ごとに分けられます。
- 「スタイル」で「黒塗り」と「白塗り+黒枠」を選べます（文書全体に適用されます）。
- 元に戻す（Ctrl+Z）・やり直し（Ctrl+Y）ができます。
- 箇所の上で右クリックすると、理由の設定・結合・分割・削除ができます（箇所リストの行でも同じ）。
- 「次の未設定」（F8、Shift+F8 で前へ）で、理由が未設定の箇所を順に確認できます。
- ページ一覧には、そのページの黒塗りと箇所数が表示されます（理由未設定があると橙色）。
- 画面下のページ番号欄に数字を入れて Enter で移動、ズーム欄で倍率を選べます。
- PDF ファイルをウィンドウにドラッグ＆ドロップしても開けます。
- ウィンドウの位置・大きさ、パネルの幅と表示、2画面/1画面は次回も引き継がれます（`settings.json` に保存。文書の情報は保存しません）。

### 検索して黒塗りする（Ctrl+F）

1. 右側の「検索」タブで語句を入れて Enter。全角・半角、大文字・小文字は区別しません。「空白を無視」がオンのときは、空白や改行をまたいだ語句（例: 行の途中で改行された氏名）にも当たります。
2. 「定型から選ぶ」で、電話番号・メールアドレス・郵便番号・12 桁の番号をまとめて探せます（正規表現も使えます）。
3. 一覧の行をクリックすると、そのヒットが黄色で示されます。黒塗りにしないものはチェックを外します。
4. 「選んだ箇所を黒塗りにする」で、ヒットごとに1箇所として追加します（理由は「現在の理由」）。元に戻す（Ctrl+Z）で一度に取り消せます。既に黒塗り済みのヒットには「済」と表示されます。

**検索は PDF の文字情報だけを対象にします。** スキャンした画像や図の中の文字、文字情報が壊れているPDFは検索できません。検索で黒塗りした後も、必ず全ページを目視で確認してください。

### その他のキー

| キー | 動作 |
|---|---|
| PageUp / PageDown | 前 / 次のページ |
| Ctrl + マウスホイール | 拡大・縮小 |
| Ctrl+0 / Ctrl+1 / Ctrl+2 | 全体 / 100% / 幅に合わせる |
| マウス中ボタンでドラッグ | 表示位置の移動 |
| F6 | 2画面 / 1画面の切り替え |
| Delete | 選択した箇所を削除 |
| Ctrl+A | 表示中のページの箇所を全て選択 |
| Ctrl+F | 検索 |
| F8 / Shift+F8 | 次 / 前の未設定へ |
| Home / End | 最初 / 最後のページ |

## 4. 2種類のPDF

### 庁内確認用PDF（`〇〇_庁内確認用.pdf`）

- 原本の上に、黒塗り箇所を**半透明の赤**で示し、番号と号番号、「【庁内確認用・外部交付厳禁】」の透かしを入れたPDFです。
- **原本がそのまま中に埋め込まれています。** 黒塗り部分の文字も読めますし、文字検索もできます。
- このPDFを公文書くろぬりで開くと、黒塗り箇所と理由が復元され、作業を続けられます。
- **絶対に外部へ交付しないでください。** 庁内の確認・保管だけに使ってください。
- ファイルサイズは原本の約2倍になります。

### 開示用PDF（`〇〇_開示用.pdf`）

- 全てのページを画像にし、黒塗りを画像に焼き込んで作り直したPDFです。黒塗りの下の文字は残りません。
- 原本の文字情報・しおり・注釈・添付ファイル・作成者などの情報は一切含まれません。
- 書き出した直後にアプリが自動で検証し、合格した場合だけ「検証済み」と表示してファイルを残します。不合格の場合はファイルを削除します。
- 文字検索・コピーはできません。ページが画像になるため、ファイルサイズは原本より大きくなることがあります。
- 黒塗りの形や大きさから、元の文字数などが推測される可能性があります。必要に応じて広めに塗ってください。

## 5. 印刷

- 「黒塗りした状態で印刷」（Ctrl+P）: 開示用PDFと同じ方法で黒塗りを焼き込んだ画像だけをプリンタへ送ります。
- 「確認用として印刷」: 原本に半透明の赤を重ねて印刷します。**原本の内容がそのまま印刷され、印刷データにも残ります。** 庁内確認以外には使わないでください。
- 印刷ジョブ名は常に「Kuronuri」で、ファイル名は送りません。

## 6. 端末に残るデータについて（重要）

本アプリは一時ファイルを作らず、レジストリや AppData にも書き込みません。ログも出しません。ただし、次のものは **Windows が管理しているため、アプリからは消せません**。必要に応じて情報システム担当課の運用で対処してください。

- ページファイル（仮想メモリ）・休止状態ファイル: メモリ上の文書内容が書き出されることがあります。
- クラッシュダンプ: Windows のエラー報告が有効な場合、異常終了時にメモリ内容が保存されることがあります。
- ファイルを開く／保存する画面の履歴: 本アプリは「最近使ったファイル」に登録しませんが、Windows がフォルダの履歴を残すことがあります。
- 印刷スプール: 印刷中のデータは Windows の印刷キューに一時保存されます。「確認用として印刷」では原本の内容が含まれます。

## 7. 対応していないPDF・注意が必要なPDF

| PDF | 動作 |
|---|---|
| 開くのにパスワードが必要なPDF | 開けません（パスワードを外したPDFを用意してください） |
| 印刷禁止などの権限だけが設定されたPDF | 開けます |
| 壊れたPDF | 読める範囲で開きます。読めない場合はエラーを表示します |
| XFA フォーム | 正しく表示できない可能性があることを警告します |
| しおり・添付ファイル付きのPDF | 開いた時に「開示用PDFには含まれない」ことをお知らせします |
| 非常に大きなページ（A0 など） | 開示用PDFでは解像度を自動で下げ、完了時にお知らせします |
| 300MB を超えるPDF | 確認用PDFの保存前に、メモリとサイズについて確認します |
| 4GB 以上のPDF | 開けません |

確認用PDFのページをそのまま取り込めない文書では、自動的に「画像方式」で確認用PDFを保存し、お知らせします（原本と黒塗り箇所は通常どおり保存されます）。

## 8. 設定

- 画面上部の「設定」（歯車）で、理由のプリセット（号番号と名称）、開示用PDFの解像度（150 / 200 / 300 dpi、既定 200）、JPEG 品質、既定のスタイル、ブラシの太さ、印刷の解像度、画面のテーマ（ライト / ダーク）を変えられます。テーマは「表示」メニューからも切り替えられます。
- 設定は `Kuronuri.exe` と同じフォルダの `settings.json` に保存されます。フォルダに書き込めない場合、設定はその起動中だけ有効になります。
- 号番号は自治体の情報公開条例に合わせて編集してください。配布前に `settings.json` を編集しておくこともできます。
- 設定ファイルには、開いた文書の名前などの情報は一切保存しません。

## 9. 困ったときは

- **原本に保存しようとして拒否された**: 原本PDF・開いている確認用PDFには上書きできません。別の名前で保存してください。
- **「出力の検証に失敗した」と表示された**: 開示用PDFは作成されていません。もう一度試し、同じ場合は原本PDFを別の方法で作り直してください。
- **予期しないエラーで終了した**: 保存していない変更は失われます。こまめに「確認用PDFに保存」してください。
