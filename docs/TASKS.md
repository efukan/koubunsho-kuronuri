# 実装タスク

上から順に進める。各タスクは「完了条件」を満たしたらチェックを入れる。設計の詳細は `ARCHITECTURE.md` の該当節を参照。

「参照コード」と書いたタスクは、`REFERENCE_CODE.md` の該当ファイルをコピーして始める（実行して合格済みのコード）。M1・M3・M4 と M2 のモデル部分は大半が参照コードの移設とテスト化で、新規に書くのは `PdfiumWorker`、Undo、グループ化、UI 一式。
